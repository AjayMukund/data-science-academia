# Same average, different penguins: standard deviation

Two groups of real penguins both average 4.7 kg, but guessing any penguin's
weight with that average lands within half a kilo 93 times in 100 in one
group and 45 in the other. The standard deviation, 280 g against 780 g, is
the number that tells them apart. On the real
[Palmer Penguins](https://allisonhorst.github.io/palmerpenguins/) data
(Horst, Hill & Gorman; collected by Dr. Kristen Gorman and the Palmer Station
LTER; CC0).

```bash
python experiment.py      # downloads the data on first run
```
