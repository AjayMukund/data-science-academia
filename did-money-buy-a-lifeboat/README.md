# Did money buy a lifeboat? Correlation vs causation

Titanic passengers who paid more survived twice as often (52% vs 25%). But
the fare stood in for class and sex, and inside third-class women, a big fare
meant a whole family on one ticket: split per person, survival is exactly
50% and 50%. On the Titanic passenger list (Kaggle training set, 891 passengers; mirror: https://raw.githubusercontent.com/datasciencedojo/datasets/master/titanic.csv; a public historical record).

```bash
python experiment.py      # downloads the data on first run
```
