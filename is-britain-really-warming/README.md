# It's four degrees in November: so is Britain really warming? Signal vs noise

The Met Office's Central England Temperature series (HadCET, 1659-2025, Open Government Licence v3). **22 November 2026 was 4.1 °C, two below the 1991-2020 normal; the same date has ranged from 0.2 °C to 12.7 °C since 1991.** Whole years wobble by only about 0.7 °C, the ten warmest of 367 years all came after 2000, and 2025, the warmest full year, still had 129 days colder than normal.

```bash
python experiment.py      # downloads the two HadCET files on first run
```

See `FINDINGS.md`. The latest daily values are provisional, so a later run may differ in the last decimal for November 2026. Try: the same test with your own city's daily temperatures.
